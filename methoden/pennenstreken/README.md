# Pennenstreken

Schrijfmethode (verbonden schrift), groep 3 t/m 8.

- Het lettertype van Pennenstreken zelf is niet vrij. We gebruiken
  **Lusletters** (`fonts/lusletters.ttf`, Liesbeth Flobbe, SIL Open Font
  License 1.1), de variant die syboor.eu aanraadt naast Pennenstreken
  (2e editie en later): <https://syboor.eu/handschrift/artikelen/welk_font_welke_schrijfmethode>.
- Stylistic set 8 geeft de hoofdletter R van Pennenstreken; `lang: "nl"` is
  nodig voor de ij. Typst verbindt de letters zelf.
- Lineatuur: vier lijnen; middenzone (romp) 5 mm, lus- en staartzone 1,5 keer
  zo hoog. Thuis naast een schoolschrift geprint en goed bevonden.

De functies staan in `vakken/schrijven/schrijven.typ`.
